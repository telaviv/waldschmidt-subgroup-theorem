directory was edited (not `LSG.lean`, `Axioms.lean`, M2.md or other code), and no git state was changed.

**Status.** Every statement listed below is proved. There is no `sorry`, `axiom` or `native_decide`. `#print axioms`

**No `KFacts` structure was needed.** The six Lemma-K♮ quadric identities (eight, with both orders of `i, j`) lie in

Build each module with `export PATH="$HOME/.elan/bin:$PATH"; lake build LSG.JacAnV.<File>`, in this order:
`PD`, `KAlg`, `KChart`, `KLemma`, `KTheta`, `Fibre`, `Laws`, `PeriodKit`, `PertLift4`, `ThetaFollow`, `FibreFTC`,

cached.

## Conventions
* `Fin 2` index `j = 0, 1` means A1's `1, 2`, that is `∂/∂z₀`, `∂/∂z₁`.
* `mIdx i j = i + j + 1`, so `℘_ij = θ_{mIdx i j}/θ₀`: `℘₀₀ = X₁/X₀`, `℘₀₁ = X₂/X₀`, `℘₁₁ = X₃/X₀`.
* `θ = D.thetaN` throughout. `pd j f z = Df(z)(e_j)`, and `cmpV Θ c = fun z => Θ z c`.
* Declarations about `ThetaData` live in `LSG.JacAn.ThetaData.*`, so that dot notation works. The generic ones live
  in `LSG.JacAnV.*`.
